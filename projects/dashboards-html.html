Lógica do negócio

Como funciona o processo

A gestão precisa acompanhar números rapidamente, mas compartilhar dashboards de Power BI depende de licenças e de um fluxo de atualização. A saída foi levar a visualização para HTML, que abre em qualquer navegador e atualiza com um arquivo.

O problemaDificuldade de compartilhar e atualizar dashboards sem Power BI Pro para todos. Uma pessoa atualizava tudo e as áreas não entendiam de dados.

Regras que governam o processo

  1. Os mesmos indicadores do Power BI, em formato leve e compartilhável
  2. A atualização não pode depender de licença individual
  3. Cada área atualiza o seu painel com um arquivo padronizado
  4. Evolução: dados em SQL Server, lidos por uma API
